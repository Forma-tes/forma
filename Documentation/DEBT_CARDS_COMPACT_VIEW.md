# Debt Cards — Compact View

Updated the Debts & Installments cards to use a denser layout while keeping all existing information visible.

- Preserves the existing Supabase-backed debt records and values.
- Keeps amount borrowed, total repayment, monthly installment, paid/remaining installments, progress, amount paid, remaining amount, interest/extra cost, loan start date, duration, next installment, linked account, edit/delete actions, and repayment action visible.
- Uses tighter spacing and smaller typography, with three columns for secondary metrics on wider cards and responsive two-column layout on small screens.
- No schema changes, migrations, or data transformations were made.
