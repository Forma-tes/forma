# Overview Account Card and Requests Spacing

- Replaced the large Accounts overview panel with a single `Total account balance` metric card using the same visual component and dimensions as Total income and Total expenses.
- Removed the per-account list and account-management controls from the Overview. Account balance is still calculated from opening balances and linked income, expenses, and transfers.
- Added explicit vertical spacing and layout isolation between the Requests summary cards and Request inbox to prevent the inbox panel from overlapping or crowding the cards above it.
